## 使うときの決まり

- **形・比率・文字の傾き・星の位置を変えない。** 画像生成で「似たロゴ」を作って代用しない
- 大きく使うとき、印刷に使うときは PNG を拡大せず、`.ai` から書き出す
- 白版（WT）は背景が透過で、文字の中が白です。白い背景に置くとフチしか見えません
- 利用条件は [AiCuty コミュニティライセンスとガイドライン](../../aicuty-guideline.md) に従います
